# Анализ данных персонажей "Песни Льда и Огня"
## Лабораторная работа №3 по введению в анализ данных

### 📋 Описание проекта
Данный проект представляет собой лабораторную работу по анализу данных о персонажах цикла произведений Джорджа Р.Р. Мартина "Песнь льда и огня". В работе используется библиотека pandas для создания и манипуляции датафреймом с информацией о персонажах Вестероса.

### 🎯 Основные задачи
1. Создание датафрейма с информацией о 10 персонажах (имя, возраст, дом, статус жизни)
2. Вывод различных представлений данных:
   - Полное содержимое датафрейма
   - Размерность таблицы
   - Названия столбцов
   - Первые 4 строки
   - Персонажи в возрасте 10-20 лет
   - Все живые персонажи
3. Дополнительное задание:
   - Добавление 3 новых персонажей
   - Создание столбца "Вероятность" (0 для мертвых, возраст для живых)
   - Визуализация обновленных данных
